# foxVPN 0.1.25 — необязательный локальный ИИ-помощник

Добавлены отдельное согласие на загрузку модели, прогресс/отмена, локальное объяснение свежей диагностики, проверка целостности модели и отдельный worker, который не открывает профиль и не меняет сетевые настройки. Применение исправлений остаётся в проверенных действиях foxVPN с существующими подтверждениями. Подробности и лицензии: [локальный помощник](local-ai.md).

Проверки повреждённой/неполной модели, размера/SHA256 потока, конкурирующих операций, отмены зависшей загрузки, устаревшей/поддельной проверки и отсутствия приватных строк в prompt входят в Rust-тесты. UI-тесты проверяют отсутствие фоновой загрузки/инференса, согласие, отмену, запрет объяснения устаревшего отчёта и отображение ответа без исполнения HTML или ремонта.

Локально прошли 123 Rust-теста, clippy с запретом предупреждений, 66 UI-тестов и TypeScript/Vite build. macOS arm64 app/helper собраны и подписаны. На настоящей Qwen3-0.6B из готового app проверены шесть публичных сценариев: рабочее HTTPS, отсутствие сервера, отсутствие ядра, несовместимый компонент, прокси Windows и неизвестная причина отказа. Также подтверждены отклонение повреждённой модели/лишних полей/слишком большого ввода и выход worker после принудительного завершения родителя. Загрузка модели с холодного внешнего диска может замедлять первый ответ; повторные тесты заняли около 3 секунд. Дополнительный процесс потреблял до примерно 1.6 ГиБ RSS во время ответа и завершался после него. Результаты CI и готовых архивов добавляются после проверки. ИИ-помощник не считается полной приёмкой VPN: Windows остаётся локальным прокси, Developer ID/нотарификация и Authenticode отсутствуют, системная leak/sleep/network-switch матрица остаётся открытой.

Подписанный архив принят root-верификатором и GUI; подмена байтов/версии и отмена отвергнуты. Настоящий bundle подготовлен в тестовой component slot без изменения системного сервиса. Оба ядра готового app прошли по 72 старта и воспроизведение прежнего отказа DNS.

macOS engine CI: https://github.com/kvashninsasha-gif/foxVPN/actions/runs/38072904821 — успешно. Первый Windows-прогон https://github.com/kvashninsasha-gif/foxVPN/actions/runs/38072904841 подтвердил 107 workspace Rust-тестов, native WinINet, 66 UI-тестов, NSIS/профиль, 72 старта установленного ядра и шесть сценариев настоящей модели с очисткой worker. Окончательный Windows-прогон после исправления устаревшего ответа остановился на лимите неавторизованного GitHub API при получении старой версии для NSIS-теста, до проверки установщика. Проверочное задание исправлено для использования штатного read-only токена GitHub Actions; Windows-канал остаётся на 0.1.24 до успешной окончательной проверки. Mac 0.1.25 готов к публикации.
