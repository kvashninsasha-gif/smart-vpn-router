# foxVPN 0.1.25 — необязательный локальный ИИ-помощник

Добавлены отдельное согласие на загрузку модели, прогресс/отмена, локальное объяснение свежей диагностики, проверка целостности модели и отдельный worker, который не открывает профиль и не меняет сетевые настройки. Применение исправлений остаётся в проверенных действиях foxVPN с существующими подтверждениями. Подробности и лицензии: [локальный помощник](local-ai.md).

Проверки повреждённой/неполной модели, размера/SHA256 потока, конкурирующих операций, отмены зависшей загрузки, устаревшей/поддельной проверки и отсутствия приватных строк в prompt входят в Rust-тесты. UI-тесты проверяют отсутствие фоновой загрузки/инференса, согласие, отмену, запрет объяснения устаревшего отчёта и отображение ответа без исполнения HTML или ремонта.

Локально прошли 123 Rust-теста, clippy с запретом предупреждений, 66 UI-тестов и TypeScript/Vite build. macOS arm64 app/helper собраны и подписаны. На настоящей Qwen3-0.6B из готового app проверены шесть публичных сценариев: рабочее HTTPS, отсутствие сервера, отсутствие ядра, несовместимый компонент, прокси Windows и неизвестная причина отказа. Также подтверждены отклонение повреждённой модели/лишних полей/слишком большого ввода и выход worker после принудительного завершения родителя. Загрузка модели с холодного внешнего диска может замедлять первый ответ; повторные тесты заняли около 3 секунд. Дополнительный процесс потреблял до примерно 1.6 ГиБ RSS во время ответа и завершался после него. Результаты окончательных файлов и CI приведены ниже. ИИ-помощник не считается полной приёмкой VPN: Windows остаётся локальным прокси, Developer ID/нотарификация и Authenticode отсутствуют, системная leak/sleep/network-switch матрица остаётся открытой.

Подписанный архив принят root-верификатором и GUI; подмена байтов/версии и отмена отвергнуты. Настоящий bundle подготовлен в тестовой component slot без изменения системного сервиса. Оба ядра готового app прошли по 72 старта и воспроизведение прежнего отказа DNS.

macOS engine CI: https://github.com/kvashninsasha-gif/foxVPN/actions/runs/38072904821 — успешно. Первый Windows-прогон https://github.com/kvashninsasha-gif/foxVPN/actions/runs/38072904841 подтвердил 107 workspace Rust-тестов, native WinINet, 66 UI-тестов, NSIS/профиль, 72 старта установленного ядра и шесть сценариев настоящей модели с очисткой worker. Промежуточный Windows-прогон остановился на лимите неавторизованного GitHub API при получении старой версии для NSIS-теста, до проверки установщика. Проверочное задание исправлено для использования штатного read-only токена GitHub Actions; окончательный успешный прогон указан ниже, оба канала уже опубликованы на 0.1.25.

## Окончательные файлы и каналы

Windows CI https://github.com/kvashninsasha-gif/foxVPN/actions/runs/38076628404 завершён успешно на окончательном коде: 107 workspace Rust-тестов, отдельный native WinINet, 66 UI-тестов, guardian, NSIS 0.1.19 → 0.1.25 с сохранением профиля, 72 старта установленного core и шесть сценариев модели из установленного EXE. Подтверждены отклонение повреждённой модели/ввода и завершение worker при смерти родителя. Полученные EXE/ядро/лицензии извлечены локально из NSIS: x64, версия, SHA256 ядра и SHA256 приложения совпали с отчётами; CRLF в тексте лицензии нормализован для сравнения. Подпись Windows EXE принята исходным ключом, подмены байтов/версии отвергнуты.

В релизе v0.1.25 опубликованы 16 проверенных assets. SHA256 и размеры всех удалённых assets совпали с локальными файлами. Исходные Mac-assets сохранены без замены; добавлены Windows-assets и отдельный SHA256SUMS-Windows. Только после проверки опубликованных файлов оба канала обновлены на 0.1.25.

Локальная установка через окно приложения пока не проверена: Mac заблокирован и ожидает ручной разблокировки пользователя; установленное приложение на момент проверки — 0.1.24. Прогоны настоящей модели относятся к готовому Mac bundle/установленному Windows EXE на тестовом runner, а не к окончательной GUI-приёмке на обоих личных устройствах.

## Дополнительная проверка интерфейса Windows

Повторно проверены опубликованный Windows-канал 0.1.25, наличие установщика и совпадение адреса скачивания с каналом. Добавлены два сценария основного окна Windows: загрузка модели только после согласия и объяснение свежего backend-отчёта без отключения соединения/изменения прокси. Исправление Windows по-прежнему требует отдельного подтверждения; его отмена не меняет соединение. Неподдерживаемые элементы macOS не показываются.

Все 68 UI-тестов и TypeScript/Vite build прошли на обоих тестовых OS runner: https://github.com/kvashninsasha-gif/foxVPN/actions/runs/38080776347. Для изменений только тестов добавлен отдельный быстрый прогон интерфейса на Windows/macOS; готовые бинарные assets 0.1.25 сохранены без замены. Проверка личного ПК через Parsec пока недоступна: Mac заблокирован, запрошена ручная разблокировка. Это не заявляется как проверка установленного приложения на личном Windows-ПК.
