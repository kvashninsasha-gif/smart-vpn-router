# Проверочные случаи аудита 0.1.26

Патч содержит три теста ожидаемого поведения. На коде `9008e4d` они должны падать; в исправленной версии — проходить. Это доказательства недостатков проверок актуальности/возврата и предпросмотра, а не испытание потери файлов на настоящем устройстве.

Тесты используют только публичные данные в памяти, не читают/сохраняют Vault и не запускают VPN. Патч не применён в основном дереве. Запускайте в временной копии проекта с обычным окружением сборки:

```sh
git apply docs/audits/0.1.26-regression-probes.patch
cargo test --locked -p smart-vpn-desktop audit_regression -- --test-threads=1
git apply -R docs/audits/0.1.26-regression-probes.patch
```

После выхода тестов с ошибкой выполните последнюю команду отдельно. Не добавляйте патч повторно после переноса этих случаев в постоянные тесты исправленной версии. [Зафиксированный результат](0.1.26-probes-result.txt).
