# foxVPN 0.1.27 — исправления первого этапа аудита

Закрыты кодом F01–F05: полный учёт пользовательской конфигурации, сохранение наблюдений, структурированное подтверждение правил, достоверный охват Mac TUN/proxy и сохранение кнопки возврата между вкладками. Добавлены общий статус настройки, отмена по opaque operation ID, защита следующей операции от запоздалой отмены и запрет отмены после точки завершения.

Локально прошли 142 Rust-теста, clippy с запретом предупреждений, 78 UI-тестов и TypeScript/Vite build. Новые тесты прямо воспроизводят случаи аудита и проверяют подписки/избранное/группы/названия/параметры, сохранение свежих замеров и отметок подписок, route diff/add/remove/IDN/wildcard/приоритет и список из 5000 правил, Mac scope и блокер отсутствующего компонента, смену вкладок, отдельное согласие и отмену/commit/позднюю отмену.

Добавлена изолированная проверка транзакции с настоящим закреплённым sing-box и настоящим encrypted Vault на временном публичном профиле. Подтверждены запрос через реальный локальный прокси, сохранение/чтение профиля, отказ контрольного endpoint (503), остановка нового ядра, возврат прежней конфигурации, повторный запуск/успешная проверка, отдельный возврат без подключения и сохранение свежих показателей. Test backend использует реальные CoreProcess, Live.save/Vault и общую функцию контрольного запроса; системная часть Live.start/stop/verify, IPC команд Tauri и действия пользователя на устройстве этим тестом не покрываются.

Фиксированный публичный ключ тестового Vault доступен только через dev feature `test-support`: тест не читает Keychain/Credential Manager и не сохраняет пользовательский профиль. Release не включает эту dev feature. Ни тест, ни сборка не останавливали работающий системный VPN Mac.

F06/F07 остаются открыты: защищённый журнал восстановления настройки после аварии и полноценный GUI rollback после неудачного следующего запуска. Windows остаётся локальным прокси; полная системная/физическая матрица, сертификаты и iPhone — отдельные этапы. Личная проверка Windows-ПК отложена пользователем. Окончательные CI/артефакты/публикация добавляются после их проверки.

## Готовая Mac-сборка и CI интерфейса

Mac arm64 app/helper 0.1.27 собраны; runtime подписи и закреплённые ресурсы проверены. Два ядра из окончательного app прошли по 72 старта и прежний отказ DNS. Настоящая Qwen3-0.6B из окончательного executable прошла шесть публичных сценариев, повреждённую модель/неизвестные поля/чрезмерный ввод и очистку после завершения родителя. Оригинальный подписанный архив принят root-верификатором и GUI; подмены/версия отвергнуты. Bundle подготовлен в временной slot без замены системного компонента. Версия, хэши отчётов, CRC ZIP и отсутствие приватных файлов проверены.

[UI Windows/macOS](https://github.com/kvashninsasha-gif/foxVPN/actions/runs/38091483582) — успешно, по 78 тестов и build. [macOS core CI](https://github.com/kvashninsasha-gif/foxVPN/actions/runs/38091483560) — успешно. Код приложения — `1e1b42c`; окончательная публикация каналов подтверждена ниже.

## Окончательный Windows-установщик и публикация
